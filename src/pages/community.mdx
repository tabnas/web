## How the project works

- **TypeScript is canonical; Go tracks it.** Changes land in TS first, then Go to match.
- **One grammar, shared fixtures.** Both implementations parse the same test grammars and must agree.
- **Small, focused packages.** The engine stays lean; languages live in their own repos.
