Every package is published to npm under the `@tabnas/*` scope and, where
applicable, as a Go module at `github.com/tabnas/<name>/go`. Each ships
four-quadrant [Diátaxis](https://diataxis.fr) docs in both languages.

Grammars are plugins over other grammars, so the list below is closer to a
dependency order than a catalogue: JSON is a handful of rules, JSONC adds
comments to them, JSON5 and jsonic relax the quoting, and so on. Extending one
of these is usually cheaper than starting a new grammar.
